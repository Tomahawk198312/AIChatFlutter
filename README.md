# AIChatFlutter - Чат-приложение с ИИ (многостраничная версия)

AIChatFlutter — мультиплатформенное приложение для общения с искусственным интеллектом, разработанное с использованием Flutter.  
Приложение поддерживает OpenRouter.ai и VseGPT.ru, предоставляя гибкие возможности для взаимодействия с различными языковыми моделями.  
Версия 2.0 добавляет многостраничный интерфейс с нижней навигацией, расширенную аналитику и удобную настройку провайдеров прямо из приложения.

## Поддержка API

### OpenRouter.ai
- Баланс отображается в долларах ($)
- Стоимость сообщений рассчитывается в долларах за миллион токенов
- Широкий выбор языковых моделей от разных провайдеров
- Единый API для доступа к различным моделям

### VseGPT.ru
- Баланс отображается в рублях (₽)
- Стоимость сообщений рассчитывается в рублях за тысячу токенов
- Доступ к популярным моделям с оплатой в рублях
- Оптимизировано для пользователей из России

## Новые возможности (v2.0)

- **Многостраничный интерфейс** с нижней панелью навигации (4 вкладки):
  - **Чат** – основной экран общения с ИИ
  - **Статистика** – сводка использования моделей (количество сообщений, токенов, стоимость)
  - **График расходов** – линейный график ежедневных затрат
  - **Настройки** – выбор провайдера, ввод API-ключа и базового URL
- **Локальное сохранение настроек** – ключ и URL провайдера сохраняются между запусками (используется `SharedPreferences`)
- **Динамическое переключение провайдера** – смена OpenRouter / VseGPT без перезапуска приложения
- **Детальная аналитика** – агрегированные данные по моделям и расходам
- Полностью сохранена вся предыдущая функциональность (история, экспорт, очистка, аналитика сессий)

## Основные модули

### ChatProvider (обновлён)
- Управление состоянием чата и историей сообщений
- Взаимодействие с API (OpenRouter/VseGPT) через динамический клиент
- Загрузка и сохранение настроек API (`api_key`, `base_url`) в `SharedPreferences`
- Агрегация ежедневных расходов (`dailyExpenses`) для графика
- Все прежние возможности: отслеживание баланса, расходов, управление моделями

### OpenRouterClient (обновлён)
- Унифицированный интерфейс для работы с API
- Поддержка динамического обновления ключа и URL (метод `updateCredentials`)
- Автоматическое определение провайдера (OpenRouter/VseGPT)
- Форматирование цен в соответствии с провайдером
- Обработка ошибок и повторные попытки

### Message (без изменений)
- Хранение текста сообщений, токенов, стоимости, метаданных

### DatabaseService (без изменений)
- Локальное хранение истории сообщений (SQLite)
- Экспорт истории, очистка, статистика

### AnalyticsService (без изменений)
- Сбор статистики использования (время ответа, токены, длина сообщений)
- Анализ эффективности моделей

## Функциональность приложения

### Основные возможности (сохранены)
- Обмен сообщениями с различными языковыми моделями
- Выбор модели из выпадающего списка с информацией о ценах и контексте
- Отображение баланса в соответствующей валюте ($/₽)
- Подсчёт стоимости каждого сообщения
- Отслеживание использованных токенов

### Управление чатом (сохранено)
- Сохранение истории сообщений в локальной базе данных
- Экспорт истории в JSON и текстовые логи
- Копирование сообщений (вопрос+ответ) в буфер обмена
- Очистка истории с подтверждением

### Аналитика и статистика (расширено)
- Статистика использования моделей: количество сообщений, сумма токенов, стоимость (экран «Статистика»)
- График ежедневных расходов в виде линейного графика (экран «График»)
- Анализ времени ответа, эффективности моделей (внутренняя аналитика)

### Настройки провайдера (новое)
- Экран «Настройки» с выбором провайдера (OpenRouter.ai / VseGPT.ru)
- Поля ввода API-ключа и базового URL
- Сохранение настроек локально, применение без перезапуска
- При первом запуске используются значения из `.env` файла

### Интерфейс
- Тёмный режим оформления
- Адаптивный дизайн
- Нижняя панель навигации для быстрого переключения между разделами
- Поддержка русского и английского языков

### Технические особенности
- Кроссплатформенность (Android, iOS, Windows, Linux)
- Локальное хранение данных (SQLite + SharedPreferences)
- Оффлайн доступ к истории чата
- Обработка ошибок сети и API

## Начало работы

1. Клонируйте репозиторий
2. Создайте файл `.env` на основе `.env.example` (опционально, можно настроить в приложении)
3. Добавьте свой API-ключ (OpenRouter или VseGPT) или введите его позже в настройках
4. Выполните `flutter pub get`
5. Запустите приложение: `flutter run`

## Конфигурация

Настройки можно указать двумя способами:
- Через файл `.env` (используется при первом запуске, если настройки не были сохранены)
- В экране **Настройки** приложения — изменения вступают в силу немедленно и сохраняются

Пример `.env`:
```
OPENROUTER_API_KEY=ваш_ключ
BASE_URL=https://openrouter.ai/api/v1
MAX_TOKENS=1000
TEMPERATURE=0.7
```
